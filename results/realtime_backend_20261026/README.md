## 实质性修复

原始在线分支的 bootstrap 会先应用整套实验性语义前端。现在独立补丁可以直接
作用于固定的几何 LIVO 上游，43 个原始文件均通过 Git blob 哈希校验；重放补丁
逐字节复现实际编译的源码，不包含实验语义头文件。

原前端 `sync_packages` 对已完成 LIO、等待当前图像 VIO 的状态，也要求新的
LiDAR/IMU输入队列非空，造成约一帧等待并传播下一包的迟到。现在当前视觉更新
无需等待未来扫描；同时复用 ROS executor，并保留原始整数图像时间戳。
视觉残差、LIO 残差和状态更新公式未改动。

图优化、位姿转发、地图发布分别执行。地图发布确认和超时状态不占用位姿回调，
优化 IPC 的完整交换有 watchdog。待处理关键帧最多两个，超载时保留最新观察。

实际编译前端的 ROS 回归检查还覆盖：停止输入后最后一张图像仍输出；暂停自有
优化进程时 12/12 位姿继续；暂停地图进程三秒时 30/30 位姿继续，延迟 P95
**1.63 ms**、最大 **1.78 ms**，显示卡住/恢复状态正确。另有 **27 项**图、
通信、生命周期与融合自动测试通过，包括半包超时和期限取消的并发回归。
