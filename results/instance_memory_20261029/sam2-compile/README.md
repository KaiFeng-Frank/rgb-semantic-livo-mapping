# SAM 2 部署复查：保留等价的 CPU 优化，编译路径未通过

**本轮没有新增语义精度成绩，也没有启用同步 SAM 2。** 得到的可用改动是一次
扫描生成所有检测框，以及按批复制最终掩码；32 帧、当前与历史两组输出均与
原未编译实现逐像素相同。它降低了开销，但仍未满足 50 ms 预算。

本轮沿用此前 512 配置的权重、层数、七份空间记忆、对象指针历史、最多四对象
批次及全部当前目标。固定使用 scene-0218 开头 32 张连续图像，覆盖记忆容量
增长阶段。YOLO 只运行一次，缓存当前掩码、ID、类别及置信度，供所有对照共用。
没有读取语义或实例 GT，没有打开新留出集，没有变更分辨率或训练模型。

## 补齐完整调用计时

前一轮 `encoder_ms + temporal_ms` 没有覆盖生成检测框、部分分配与最终输出
整理。本轮用实际整个调用耗时减去配对的当前组计时，保留其余开销。此口径
还包含少量未单列的当前组输出整理，因此是对历史组成本的保守计量。

| 同输入 32 帧对照 | 中位耗时 | p95 | 非首帧最大值 |
|---|---:|---:|---:|
| 原未编译实现，完整调用计时 | 85.51 ms | 101.01 ms | 293.53 ms |
| 等价的 CPU 布局优化，未编译 | 66.84 ms | 82.60 ms | 260.88 ms |

表中分布用第 1–31 帧；第 0 帧分别为 629.23 / 641.69 ms，未隐藏在稳态均值中。
模型初始化另为 1.14 / 1.14 秒。两组各一次独立进程，均为本机 RTX 5070 Ti
Laptop、CPU 12–15 亲和性、Torch 单线程、低优先级；没有其他 GPU 实验竞争。
这些是组件回放，未包含 YOLO、PTv3 或 ROS，也不是三次重复的部署验收。
完整逐帧值见 [eager](eager)、[eager-layout](eager-layout) 和
[complete-call-timing.json](complete-call-timing.json)。

CPU 框生成单独在核心 10 上重复三次：中位耗时 16.56 → 1.26 ms，所有框坐标
精确一致。`scipy.ndimage.find_objects` 一次遍历标签图，仍取每个实例的所有
像素（包括不连通碎片）的最小外接框。无支持像素的 ID 仍为空。批量复制和
直接写入输出数组不改变模型前向、阈值或掩码。[最终掩码比较](layout-equivalence.json)
在两组全部 32 帧上为零差异；这是实现等价性，不是 GT 精度。

## 官方编译路径的三次执行记录

[官方 SAM 2](https://github.com/facebookresearch/sam2)提供整模型编译的 VOS 子类。
本适配器通过原 `build_sam2` 创建该子类，以保留原有后处理设置；直接换成
视频构建器会额外改变提示掩码二值化等设置，未这样做。

1. [initial](initial)：在第二帧读取历史时，编译后的 memory attention 输出
   被后续 CUDA 图复用，进程报错退出。首帧全部计算和编译约 112.84 秒。
2. [owned](owned)：在图外复制该中间特征后，发现 512 位置编码首次在图内
   生成并被对象缓存，仍出现存储复用错误。保留独立日志。
3. [owned-rope](owned-rope)：提前在图外计算相同的原生位置编码后，完成了
   全部 32 帧；但重置历史后的第一次重复在第 0 帧触发输出不一致检查。
   没有获得三次完整的预热后时延结果。

第三次的首轮输出也没有通过事先固定的未编译等价性门槛：所有非空实例掩码
平均 IoU 为 **0.97980**，低于 0.99；最小值为 0，低于 0.95。
逐像素差异占整幅数组的比例虽仅为 0.00603%，但大量背景像素会稀释局部对象
差异，因此没有用该平均值豁免对象级失败。这些 IoU 比较的是两个实现，
**不是与 GT 的分割精度**，也不能推出编译后的预测一定更差。
见 [compile-equivalence.json](compile-equivalence.json)。

两处明确的张量生命周期错误已做对应修复；重复输出差异尚未定位为一个
确定根因。未继续调精度、模型规模、记忆容量或编译参数来追过线。编译选项
保持关闭，失败结果不替代原 1024 / 512 的性能记录。

## 保存与校验

运行前固定的协议提交为 `64be52f`；两次生命周期修复为 `d2d99e9`、`cf3daff`，
布局优化为 `9624e06`。各目录包含该次执行的精确源文件快照。比较器后来补齐
完整调用计费，并拒绝缺失的三次预热结果，源码为 `comparison.py.snapshot`。
缺失数据不会因 `all([])` 而通过门槛。

[input-manifest.json](input-manifest.json) 和 [mask-cache-hashes.json](mask-cache-hashes.json)
保存本地输入与紧凑输出的哈希；原始图像、大掩码和编译二进制不提交。
四项状态、几何边界与结果准入测试通过，见 [tests.log](tests.log)。
[validation.json](validation.json) 核对快照哈希、逐像素比较和完整计时。

当前可保留的是等价的实现优化。同步多目标 SAM 2 的耗时仍未达标，语义改善与
实例泛化目标继续未完成；已有连续图像跟踪的正面结果不受此实验替代。
