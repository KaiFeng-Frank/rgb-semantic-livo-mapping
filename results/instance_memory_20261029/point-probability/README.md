# 历史语义为什么改错：对应关系与概率信息

**置信度信息改变了结论，但还不能启用当前方案。** 固定的概率混合使全扫描
mIoU 增加 0.611 pp，6/8 开发日志超过原始与当前邻域两种对照；相机内前景
准确率却下降 0.276 pp，违反预先固定的 0.1 pp 最大损失。没有降低门槛、
搜索混合系数、训练新头或打开新的四日志留出集。

## 先复现失败，再拆原因

[causes](causes) 完整重现上一轮八日志、321 帧的原始混淆矩阵，然后仅在
**使用 GT 的诊断分支**删除错误对应。保留下来的历史标签仍是原始模型预测，
不注入正确答案 logits。这些分支不能部署，也不是所有时序模型的上界。

| 对照 / 特权诊断 | native16 mIoU |
|---|---:|
| 原始 PTv3 | 53.07456% |
| 原始历史硬标签投票 | 52.25746% |
| GT 删除不同语义类别的历史邻居 | 52.89171% |
| GT 再要求前景同实例 | 52.91843% |

原投票改错 114,676 点，其中 72,952 点的所有有效历史邻居都属于正确的
GT 类别，约占 63.6%。GT 类别过滤避免 36,159 个原有错误，却仍留下 78,546
个错误（包括新引入的 29 个）。94.1% 的原有伤害落在背景类。
因此不能把失败全部归因于动态目标或跨实例关联；同类历史的预测也可能错误。
两种 GT 过滤都未超过原始 PTv3，单改对应关系不是已经证实的解决方案。

## 固定总权重，恢复原始概率

硬投票把每个邻点当成一票，单个历史扫描最多可以用四票压过当前点的一票；
同时把原始预测置信度丢掉。后续对照保持相同 25 cm 半径、四邻点、上一原始
扫描和 0.75 秒时限，只使用仓库已有 `UniformFusion` 的固定 50/50 概率公式：

`p = 0.5 * 当前点原始概率 + 0.5 * 有效历史邻点原始概率的均值`

无历史时精确返回当前输出；完全并列时保留当前类别。历史只存原始概率，
从不写回融合结果。当前空间邻域控制使用同一公式和预算，排除当前点自身。
所有四组共享新的一次 PTv3 前向，没有跨运行拼接准确率。

| 同次前向对照 | native16 mIoU | 相机内前景准确率 |
|---|---:|---:|
| 原始 PTv3 | 53.07671% | 84.49587% |
| 当前空间邻域概率 | 53.05513% | 84.40826% |
| 上一原始扫描概率 | **53.68768%** | 84.22016% |
| 上一原始扫描硬投票 | 52.25570% | 83.82849% |

相对原始预测，概率记忆修正 53,350 点、改错 51,525 点；相比硬投票显著减少
伤害，但仍有取舍。自行车和摩托车 IoU 分别提高 5.386 / 5.168 pp；
行人、卡车分别下降 0.173 / 0.773 pp，不能据整体均值宣称行人能力改善。
原始类别按 native16 定义；这不是 SemanticKITTI 19 类或榜单成绩。

本次重新提取与旧缓存有 3,053 个原始点标签不同，因此旧分数只用于复现限制
说明。正式对照全部来自相同新前向。CPU 两种邻域检索及读出合计 p95
111.12 ms；同步骨干 p95 为 34.11 ms，冷最大值为 730.39 ms。这些不是
在线 ROS 延迟，也不满足据此直接宣称 10 Hz 的条件。

实验配置在运行前提交为 `4f37cdc`。完整配置、分日志指标、数据和源文件哈希、
相同前向的全部混淆矩阵见 [equal-frame](equal-frame)。结果明确 `passed=false`。
这个概率读出版本到此停止，不用继续调系数来追过线。

## 与真正的特征记忆的区别

目前证据否定的是这些具体的标签/概率读出，不能替代对已训练的特征记忆的验证。
[MemorySeg 官方说明](https://waabi.ai/research/memoryseg)将点和体素表征与稀疏
潜在记忆联合解码；[SAM 2 官方实现](https://github.com/facebookresearch/sam2)
提供带流式记忆的预训练视频分割模型。它们都不等同于重复历史硬标签。

下一项独立可行性检查复用官方 SAM 2.1 Tiny，对同一当前检测框比较清空历史与
读取历史的掩码。PTv3、检测类别和跟踪 ID 保持同源；原生 SAM 2 会递归编码
预测掩码，因此需要直接检查错误传播，不能沿用“只存原始语义概率”的保证。
先固定八帧多目标场景测实际成本，再决定是否进行完整语义/身份评价。
官方 A100 帧率不作为本机性能证据。此处没有 SAM 2 精度或实时性成功声明。
