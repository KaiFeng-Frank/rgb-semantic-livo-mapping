# SAM 2 特征记忆：同步运行的成本检查未通过

**两种固定输入分辨率都未满足 50 ms 的 SAM 模块预算，未启动完整精度回放，
未接入默认实时链路。** 这检验了一个具体实现配置，不证明所有视频记忆方法
都不可实时，也没有 SAM 2 在本数据上的精度成绩。

本轮动机是此前类别/概率平滑不足以同时改善整体语义和前景，而预训练的视频
特征记忆提供了另一种可直接检查的实际能力。
[官方 SAM 2](https://github.com/facebookresearch/sam2) 提供视频记忆和预训练权重；
其 README 帧率在 A100 上测量，不能替代此处本机、多目标、实际输入的成本。

## 固定条件

- 官方源码固定为 `2b90b9f5ceec907a1c18123530e92e794ad901a4`，仓库未修改。
- SAM 2.1 Hiera Tiny，官方权重 SHA-256
  `7402e0d864fa82708a20fbd15bc84245c2f26dff0eb43a4b5b93452deb34be69`，
  156,008,466 字节。下载经官方 Hugging Face LFS 哈希核验，权重留在 runtime，
  不提交到 Git。下载来源、失败及残文件清理见 [acquisition.json](acquisition.json)。
- 原先固定的 scene-0218 连续图像索引中前八帧，每帧 9–12 个有实际像素支持的
  当前检测实例。全部参与；不按 GT、难度或耗时挑选对象。初始未支持的空掩码
  保持为空，不凭空生成框。
- 两组共用一次当前图像编码、相同检测掩码派生的框、相同模型权重。
  当前组每帧清空记忆，时序组只读取过去的原生 SAM 2 掩码特征与对象指针。
  YOLO 提供类别和 ID，没有 GT 提示、未来图像或新增训练。
- 原生七份空间记忆（初始条件帧加六份近期记录），原生有界对象指针历史，
  最多 128 条轨迹、缺失 2 秒过期、每批最多四个目标。会话变化或图像间隔
  超过 0.75 秒重置。旧空间特征被释放，只保留仍需使用的小型指针。
- 本机 RTX 5070 Ti Laptop，单 CPU 核 14、单 Torch 线程、低优先级，BF16，
  不编译。启动前检查没有其他 GPU 计算进程，完整环境见 [environment.json](environment.json)。

原生 SAM 2 会递归编码自己预测的掩码，这是其预训练设计。本适配器明确保留
这种行为，**不声称满足此前“只存原始语义概率”的无反馈条件**。

## 实际结果

| 配置 | SAM 单独中位延迟 | p95 | 最大值 | 门槛 |
|---|---:|---:|---:|---|
| 默认 1024 | 218.32 ms | 333.43 ms | 372.62 ms | 失败 |
| 一次性改为 512 | 66.71 ms | 208.83 ms | 264.35 ms | 失败 |

表中包含该帧图像预处理、共享编码器、时序掩码读出、记忆更新、原图尺寸恢复及
CPU 输出，不包含配对的当前组读出，也不包含 YOLO、PTv3 或 ROS。
排除首帧后仅七次测量，**p95 是这个小型启动探针的统计，不是稳态延迟分布**。
首次进入新历史计算形状的开销保留；512 的后续中位数也仍超过 50 ms。
第一帧、各子阶段、启动时间、GPU 峰值和全部逐帧值均保留在
[probe-1024.json](probe-1024.json)、[probe-512.json](probe-512.json)。

两组首帧在没有历史时输出逐像素一致。之后实际读取历史的对象每帧为 8–11 个，
掩码确实变化。因此这不是空记忆开关；但变化像素数不是精度证据。
没有读取 GT 类别/实例来给这两次探针打准确率分数。

512 是根据标准配置的运行成本作出的单次调整，发生在任何 SAM 2 精度评分之前。
它使空间 token 数降为四分之一，注意力位置对数量降为十六分之一，权重、层数、
记忆长度和其他设置不变；实际耗时仍以测量为准。它不是预训练默认输入尺寸，
即便速度通过也必须另外验证精度。两个预登记配置在 `config/sam2_memory_probe*`
中，原 1024 失败没有被覆盖，之后没有继续搜索分辨率、模型规模或记忆长度。

## 代码和边界

[sam2_memory.py](../../../tools/visual_instances/sam2_memory.py) 包装官方低层接口，
复用当前图像编码并按相同历史布局批处理对象；它仍是实验代码，不是部署完成的
节点。状态测试检查有界空间记忆、指针保留、过期特征释放和独立张量存储。
两次运行的精确源文件快照与报告 SHA 已核对。

这个结果要求重新设计同步读取的成本，而不是把模型放进实时主循环后再忽略
积压。当前保留已验证的连续图像跟踪链路；本次没有把慢模型的潜在收益写成
语义/实例提升，也没有用它替代 PTv3。
